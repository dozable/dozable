# Fix the problem

Describe the problem here (or in the room): what fails, how often, and where. Find out why, fix it, and add a
regression test that fails before the fix and passes after it.

- Builder: build after each change and say what changed.
- Tester: run the full suite after each build; record each run's outcome in the journal.
- Reviewer: review every change, read-only; propose a lesson when the same problem comes back.
- Helper: keep notes of what was tried and why, in the notes folder.

Done when the regression test is in, the suite passes ten runs in a row, and the reviewer has no open findings.
