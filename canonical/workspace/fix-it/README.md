# fix-it

The workspace template "Fix-it team" that doz ships — a builder and a tester share a Sandbox; a reviewer reads; a helper keeps notes. Its agents: manager (manager), builder (sandbox), tester (sandbox), reviewer (fenced), helper (fenced); the room: you and all 5 agents · its history kept between runs; the network: Standard + npm. The file here, with its placeholders, is the one source of the template doz carries.
