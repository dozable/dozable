# app

The canonical demo workspace: a manager bot and four agents fix a flaky login test in one project — a builder and a
tester sharing one Sandbox, a reviewer fenced on this Mac that only reads, and a helper that keeps notes — with the
room's history kept between runs. It is the one file that shows Dozable's major features at once, for screenshots,
posts, the manual and demos; this README is also the project readme its brief points the agents at (`refs:`).
